Schema validation, compiled.

Describe your data with a small DSL or with JSON Schema (draft-04 to 2020-12). schiva turns the schema into a JavaScript function written for it, so every value is checked at full speed, with errors you can show as they are.

Get started 
import { ClosedSchema, String, Integer, ArrayOf } from 'schiva';

const person = new ClosedSchema({
  id: String(),
  age: Integer({ min: 18 }),
  tags: ArrayOf({ type: String(), isMandatory: false }),
});

const validate = person.compile();

validate({ id: 1, age: 10, extra: 1 });
// ['id must be a string',
//  'age must be at least 18',
//  'Unexpected key: extra']
import { compileJsonSchema } from 'schiva';

const validate = compileJsonSchema({
  type: 'object',
  required: ['id', 'age'],
  additionalProperties: false,
  properties: {
    id: { type: 'string' },
    age: { type: 'integer', minimum: 18 },
    tags: { type: 'array', items: { type: 'string' } },
  },
});

validate({ id: 'x', age: 20 }); // []

Why schiva

Small, strict and fast, with nothing to install besides itself.

Compiled to code

Each schema becomes a function generated for it, in about 0.1 ms (40 times faster than ajv), or written out as a module when building, for strict Content Security Policies.

Complete JSON Schema

Passes every test of the JSON-Schema-Test-Suite from draft-04 to 2020-12: 4950 of 4950, dynamic references and unevaluatedProperties included.

Two schema languages

A short DSL for schemas that live in your code, with their TypeScript types inferred. JSON Schema for schemas you share. Same engine.

Readable errors

Plain strings with the path of each field: lines[12].price must be a number.

Strict by default

A misspelled or unsupported keyword throws when compiling instead of being silently ignored.

Zero dependencies

CommonJS and ESM, Node.js 18 and later, and browsers through any bundler. MIT licensed.

Faster than ajv in every benchmark we run. Measured against ajv and @exodus/schemasafe with the validators of json-schema-benchmark, each in its own process, in first-error mode unless stated. Higher is better.
